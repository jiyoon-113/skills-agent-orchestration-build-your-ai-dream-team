# Agent team

Here is a summary of the custom agents I will use to build Mona's Project Pulse dashboard.

Orchestrator
Target model: GPT-4
Responsibility: Orchestrate the workflow and manage tasks (전대진 - AI 아키텍처 및 파이프라인 설계)
Location: .github/agents/orchestrator.md

Planner
Target model: GPT-4
Responsibility: Plan the project steps and analyze requirements (오지윤 - 프롬프트 및 페르소나 최적화)
Location: .github/agents/planner.md

Coder
Target model: GitHub Copilot
Responsibility: Write code and build features (신지윤 - 백엔드 서버 구축 및 API 연결)
Location: .github/agents/coder.md

Designer
Target model: GPT-4
Responsibility: Design the UI and visual assets (백예원 - 프론트엔드 UI/UX 및 실시간 통신 개발)
Location: .github/agents/designer.md

Note: I am using GitHub Copilot CLI in a Codespace to orchestrate the work.
