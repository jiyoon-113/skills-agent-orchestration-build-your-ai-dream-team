# Agent team

Here is a summary of the custom agents I will use to build Mona's Project Pulse dashboard.

* **Orchestrator**
  * Target model: GPT-4
  * Responsibility: Orchestrate the workflow and manage tasks.
  * Location: `.github/agents/orchestrator.md`

* **Planner**
  * Target model: GPT-4
  * Responsibility: Plan the project steps and analyze requirements.
  * Location: `.github/agents/planner.md`

* **Coder**
  * Target model: GPT-4
  * Responsibility: Write code and build features.
  * Location: `.github/agents/coder.md`

* **Designer**
  * Target model: GPT-4
  * Responsibility: Design the UI and visual assets.
  * Location: `.github/agents/designer.md`

Note: I am using GitHub Copilot CLI in a Codespace to orchestrate the work.
